# Домашнє завдання: IaC (Terraform) — Lesson 5

Проєкт розгортає базову інфраструктуру AWS із використанням модульного підходу Terraform та віддаленого зберігання стану (Remote State) у S3 з блокуванням через DynamoDB.

## 1. Структура проєкту

```text
lesson-5/
│
├── main.tf                  # Головний файл для підключення модулів та провайдера AWS
├── backend.tf               # Налаштування віддаленого бекенду (S3 + DynamoDB)
├── outputs.tf               # Загальне виведення вихідних даних усіх модулів
│
├── modules/                 # Каталог з інфраструктурними модулями
│   ├── s3-backend/          # Модуль створення S3-бакета та таблиці DynamoDB
│   │   ├── s3.tf
│   │   ├── dynamodb.tf
│   │   ├── variables.tf
│   │   └── outputs.tf
│   │
│   ├── vpc/                 # Модуль мережевої інфраструктури (VPC, Subnets, IGW, NAT, Routes)
│   │   ├── vpc.tf
│   │   ├── routes.tf
│   │   ├── variables.tf
│   │   └── outputs.tf
│   │
│   └── ecr/                 # Модуль реєстру Docker-образів ECR
│       ├── ecr.tf
│       ├── variables.tf
│       └── outputs.tf
│
└── README.md                # Документація проєкту
```

## 2. Пояснення модулів

s3-backend — створює приватний S3-бакет із увімкненим версіюванням та шифруванням для централізованого зберігання terraform.tfstate, а також таблицю DynamoDB (LockID) для блокування стейту під час одночасного запуску команд.

vpc — розгортає ізольовану віртуальну мережу VPC (10.0.0.0/16), 3 публічні та 3 приватні підмережі у трьох зонах доступності (us-west-2a, us-west-2b, us-west-2c), Internet Gateway для доступу публічних підмереж до інтернету, NAT Gateway (з Elastic IP) для вихідного трафіку приватних підмереж та таблиці маршрутизації (Route Tables).

ecr — створює приватний репозиторій AWS Elastic Container Registry (lesson-5-ecr) з автоматичним скануванням образів при завантаженні (scan_on_push = true) та налаштованою політикою доступу для поточного AWS-акаунту.

## 3. Команди для ініціалізації та запуску

### Ініціалізація робочої директорії та завантаження провайдерів/модулів

terraform init

### Перевірка плану змін перед створенням ресурсів

terraform plan

### Застосування конфігурації та створення інфраструктури в AWS

terraform apply

### Видалення всієї створеної інфраструктури після завершення роботи

terraform destroy
